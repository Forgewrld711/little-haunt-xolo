# Little Haunt: Xolo — submission draft

## Short description

A tiny hairless xolo haunts the browser tab you choose. He rolls a pumpkin, gives your cursor one brief ghostly flicker, and leaves instantly when asked. If his portrait fails to load, he returns under a sheet.

## What it haunts

Real Chrome or Edge browser tabs. The extension injects its overlay only after the user clicks **Invite the xolo** on a normal website.

## Safety and scope

No account, network service, tracking, page reading, or persistent site access. The effect is opt-in, temporary, and reversible by either the in-page × or the extension popup. Navigation clears it. Reduced-motion preference disables the animation and cursor trick.

## How it was made

Manifest V3 browser extension with plain JavaScript and CSS. The transparent xolo portrait was generated with OpenAI's built-in image tool; the original placeholder and final image prompt remain in the repository. Miranda Price directed the concept and built it with Codex assistance.

## Demo beats

Normal tab → invite the xolo → pumpkin roll and brief cursor flicker → send him home → normal tab again. A silent 20–30 second screen recording is enough.
